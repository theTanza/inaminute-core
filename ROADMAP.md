# Roadmap

The public roadmap favors correctness, explainability, and reusable foundations.

## Next

- Represent sections with multiple weekly meeting blocks.
- Add optional hard constraints without changing soft-ranking defaults.
- Publish property-based tests for conflict and determinism invariants.
- Add benchmark fixtures and documented performance budgets.

## Later

- Introduce pruning for large candidate spaces.
- Support pluggable scoring components with normalized weights.
- Add JSON import/export schemas with explicit versioning.
- Provide integration guides for web services and local-first applications.

Roadmap items are proposals, not commitments. Open an issue with a concrete use
case before starting substantial work.
